## 🚀 Meu Primeiro Código em Python (Cálculo de Média)
Este é o algoritmo que desenvolvi para as aulas de lógica da faculdade:

```python
# Programa para calcular a média aritmética de alunos
nota1 = float(input("Digite a primeira nota: "))
nota2 = float(input("Digite a segunda nota: "))

media = (nota1 + nota2) / 2

    print("Status: Aprovado!")
else:
    print("Status: Reprovado!")
```
